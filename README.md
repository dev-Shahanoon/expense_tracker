# 💰 Expense Tracker

A modern Flutter-based personal finance and expense tracking application designed to help users manage multiple accounts, track income and expenses, monitor balances, analyze spending, and securely backup their financial data.

Built with **Flutter** and **Dart**, using **Hive** for local data storage.

---

## 📱 About the Project

Expense Tracker is a personal finance management application that provides a simple and organized way to manage money across multiple bank accounts and wallets.

The app allows users to:

- 🏦 Manage multiple accounts
- 💵 Track income
- 💸 Track expenses
- 🔄 Transfer money between accounts
- 📊 View overall financial statistics
- 💳 View individual account balances
- 📈 Analyze monthly spending
- 🔎 Search and filter transactions
- ✏️ Edit transactions
- 🗑️ Delete transactions
- 📤 Export transactions to CSV
- 💾 Backup and restore data
- 🔐 Protect the app with biometric authentication
- 🌙 Use Light or Dark mode

This project was developed as a practical Flutter application to gain experience in real-world mobile application development, local data persistence, financial calculations, UI design, file handling, and application security.

## ✨ Features

### 🏦 Multiple Accounts

Create and manage multiple financial accounts such as:

- Bank accounts
- Cash
- Wallets
- Credit cards

Each account maintains its own balance.

---

### 💵 Income Tracking

Record income from different sources:

- Salary
- Freelance
- Business
- Investment
- Gift
- Refund
- Other income

Income is automatically reflected in the selected account balance.

---

### 💸 Expense Tracking

Record expenses using different categories:

- 🍔 Food
- 🚗 Transport
- 🛍️ Shopping
- 🏠 Bills
- 📚 Education
- 💊 Health
- 🎬 Entertainment
- 🛒 Groceries
- ✈️ Travel
- 📦 Other

---
